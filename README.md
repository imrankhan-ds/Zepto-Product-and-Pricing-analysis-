# Zepto Product & Pricing Analysis

## Project Overview

This project analyzes Zepto product data using SQL to understand product pricing, discounts, ratings, and category-wise product distribution.

The analysis focuses on identifying pricing patterns, highly discounted products, highly rated products, and category-level trends using MySQL.

## Dataset

The dataset contains 766 product records with the following attributes:

- Category
- Product Name
- Price
- Pack Size
- Rating
- Original Price
- Discount

After importing the dataset into MySQL, 764 valid records were available for analysis.
